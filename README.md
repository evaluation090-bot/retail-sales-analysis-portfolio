# Retail Sales Analysis Portfolio

## Business question
Which products, regions, and months drive or reduce retail sales performance, and where should the business focus to improve revenue and profitability?

## Dataset
- **File:** `data/raw/retail_sales_raw.csv`
- **Contents:** Generated sample retail transactions covering January 2025–March 2026.
- **Fields:** Order ID, customer ID, product, category, quantity, unit price, sales amount, order date, region, and payment method.
- **Intentional quality issues:** Duplicate rows, missing values, inconsistent category/region casing, extra whitespace, and mixed date formats.

## Tools used
- Python and pandas for profiling, cleaning, validation, and export
- SQL (PostgreSQL syntax) for aggregation, ranking, and month-over-month analysis
- Power BI for interactive dashboarding
- Excel for validation and monthly reporting

## Cleaning approach
1. Preserve the original raw file and work from a copy.
2. Profile missing values, duplicates, data types, category values, and date formats.
3. Standardize text fields, including category and region names.
4. Remove duplicate records.
5. Exclude records missing required dates, quantities, prices, or sales amounts from the analysis dataset.
6. Convert order dates to a consistent date format.
7. Validate row counts and totals after cleaning.

## Key metrics
- Total revenue
- Total orders
- Total quantity sold
- Average order value
- Estimated gross profit
- Estimated profit margin
- Month-over-month revenue growth
- Revenue by region
- Revenue by product category
- Top 10 products by revenue

## Important assumption
Gross profit is estimated as 28% of sales because the sample data does not contain product costs. This is an illustrative assumption, not actual company profitability.

## How to run
```bash
pip install -r requirements.txt
python scripts/clean_retail_sales.py
```

Run the SQL against a table named `cleaned_sales` after importing `data/cleaned/retail_sales_cleaned.csv` into PostgreSQL.
