# AI Response Evaluation Rubric

## Scoring scale
| Score | Meaning |
|---|---|
| 5 | Excellent: accurate, complete, clear, well formatted, and follows instructions |
| 4 | Good: mostly accurate and complete, with minor issues |
| 3 | Acceptable: partially answers the request or has noticeable gaps |
| 2 | Poor: significant factual, relevance, or instruction-following problems |
| 1 | Unacceptable: incorrect, unsafe, irrelevant, or fails the core request |

## Evaluation criteria
1. **Factual accuracy:** Are claims correct and appropriately qualified?
2. **Relevance:** Does the response address the actual user request?
3. **Completeness:** Does it answer every part of the prompt?
4. **Clarity:** Is it easy to understand and logically organized?
5. **Tone:** Is the language appropriate and professional?
6. **Instruction-following:** Does it follow format, length, tone, and content constraints?

## Common failure patterns
- Confidently stating unsupported facts
- Answering only part of a multi-part prompt
- Ignoring requested formatting or constraints
- Repeating information unnecessarily
- Making assumptions instead of acknowledging ambiguity

## Evaluation workflow
1. Read the prompt and identify the required outcome.
2. Check factual accuracy before assessing style.
3. Score every criterion independently.
4. Record a short justification for scores of 1–3.
5. Flag responses that could mislead, harm, or materially confuse a user.

## Calibration
Reviewers should score the same sample responses before independent evaluation. Discuss scores that differ by more than one point. A practical consistency target is at least 80% agreement within one score point.
